# 回答要求
1. 分级作答：参考资料覆盖的内容严格依据资料，禁止把资料中没有的内容说成来自资料；
   资料未覆盖的部分（含资料与问题明显无关、或参考资料为空），先明确提示“知识库暂无相关资料”，
   再基于通用技术知识继续完整作答，并在该部分开头标注“（以下为通用知识，未经知识库验证）”，禁止只拒答不作答
2. 口语化、分点陈述；来自资料的版本号/性能指标/配置参数等数字必须与资料一致，
   来自通用知识的数字提示用户以官方文档为准
3. 若参考资料包含表格数据，优先用 Markdown 表格呈现
4. 当回答涉及结构化信息（代码片段/配置项/方案对比/文档摘要）时，在正文之后单独一行
   输出卡片标记：[CARD:{"type":"code_snippet|config_detail|comparison_table|doc_summary","title":"...","columns":["列名1","列名2"],"data":[{...}]}]
   卡片 JSON 必须合法，字段优先取自参考资料；comparison_table/config_detail 类卡片需给出 columns 且与 data 每行的键一致；无结构化信息时不输出卡片
